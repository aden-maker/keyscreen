## 1. 项目名称
KeyScreen：会被 AI 改造的多语言触屏键盘

## 2. 参考方向
AI + 智能硬件 / 人机交互（AGH 驱动真实设备的智能体应用）

## 3. 摘要（约 200 字）
KeyScreen 把一块 LubanCat 1H 触摸屏变成即插即用的 USB 键盘，并通过 Agnes Harness（AGH）+ 设备协议 MHS 让 agnes-3.0-flash 直接读写键盘硬件。用户一句"我要写俄语论文了"，Agnes 会连续完成读取设备状态、切换俄语键盘、浏览并挑选壁纸、设置主题色、指挥桌宠、复核状态等多步操作，电脑端布局 1 秒内自动跟随。键盘同时提供英/俄/法/德四种语言、整句拼音输入法、按键落点统计与 AI 调键位。我们给出了真实设备上的正常/边界/失败测试样例、AGH 执行记录导出和一项诚实报告负结果的校准对照实验。

## 4. 问题来源与目标
- 来源：队员写外语作业时需要俄语/法语键盘，购买实体键盘或贴纸成本高、切换麻烦；触屏键盘对所有人用同一套键区，手指落点偏差导致误触；大模型多停留在聊天，很少真正操作身边硬件。
- 目标：① 一块屏幕 = 四种语言键盘，所见即所得；② 让 AI 能"看见"打字数据并动手改硬件；③ 一句话完成多步场景配置，过程可审计、可复现。

## 5. AGH 的作用（≥3 个连续步骤）
AGH 是系统的智能体底座：PC 端面板把用户的话交给 `agh -p … --mode json`，AGH 负责会话、工具路由和执行记录；MHS 设备 `keyscreen-01` 把键盘暴露为工具。一次真实的"俄语写作"任务中 Agnes 连续执行：
1. `read_device` 读取当前语言/壁纸/配色；
2. `set_language(ru)` 切换俄语键盘；
3. `list_wallpapers` 浏览可选壁纸；
4. `set_wallpaper` / `set_profile` 设置安静壁纸与沉稳主题色；
5. `pet_act(cheer)` 让桌宠加油；
6. 再次 `read_device` 复核生效，并用中俄双语回复。
完整记录见 `运行证据/agh_ru_writing.html`（AGH `export` 导出，已自动脱敏）。

## 6. 模型信息
| 项 | 内容 |
|---|---|
| 模型名称/版本 | Agnes `agnes-3.0-flash` |
| 使用阶段 | 运行时：意图理解与任务规划 → 工具调用执行 → 结果复核 → 生成回复；数据分析：读取触点统计给出调键建议 |

## 7. 数据 / 代码 / 软件 / API / 设备接口
- 设备：LubanCat 1H（RK3566，Debian 10）+ 触摸屏；USB OTG 以 configfs HID gadget 模拟标准键盘。
- 板端 REST API（aiohttp）：`/api/profile` `/api/lang` `/api/wallpaper` `/api/keys/adjust` `/api/stats` `/api/chat` 等。
- MHS 设备工具：`read_device` `get_touch_stats` `adjust_key` `set_language` `set_wallpaper` `set_profile` `list_wallpapers` `pet_say` `pet_act`。
- 软件：Python 3、pygame、aiohttp、jieba、pypinyin、Agnes Harness / MHS SDK；电脑端 Windows 键盘布局 API（LoadKeyboardLayout）。
- 数据：板上真实按键日志（649 次基线、1434 次累计），实验脚本 `desktop/experiment.py`；第三方素材见《第三方素材与数据来源声明》。
