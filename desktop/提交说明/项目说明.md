# KeyScreen：会思考的触屏键盘

2026 江苏省 AI+科学与工程创新实践黑客松 参赛作品

## 一句话介绍

一块触摸屏（LubanCat 1H）插到电脑上就是一把标准 USB 键盘；接入 Agnes（agnes-3.0-flash），通过设备协议 MHS 读取打字数据、调整键位、更换壁纸、指挥看板娘，让键盘随人、随场景变化。

## 功能

- **即插即用 USB 键盘**：板子模拟标准 HID 键盘，任何电脑免驱使用；多点触控、组合键、长按连发。
- **Agnes 助手**：键盘上半屏即对话框，内置搜狗式整句拼音输入法（4.7 万词条、简拼、自学习），中英一键切换。
- **AI 动手改硬件**：Agnes 通过 MHS 工具 `get_touch_stats / adjust_key / set_wallpaper / pet_act …` 读数据、改键位，每次调用都有日志。
- **天气卡片 + 视频壁纸 + 看板娘**：苹果风格天气小组件，可拖拽、会跑跳的看板娘。
- **开机自启 + 离线保底**：板子 systemd 自启，电脑登录后自动连接；Agnes 不可用时本地规则兜底，天气使用缓存。

## 架构

```
触摸屏 → LubanCat 1H（渲染/判键/输入法/看板娘） → USB HID → 电脑
                     ↕ USB 网络（REST API）
          MHS 设备 keyscreen-01 ⇄ AgnesHub / AGH ⇄ agnes-3.0-flash
```

## 实测指标

| 指标 | 数值 |
|---|---|
| 触摸 → USB HID 发送 | 平均 1.75 ms，p95 3.3 ms |
| 按键 → 屏幕更新（助手输入） | 中位数约 34 ms |
| 屏幕刷新耗时 | 48 → 27 ms（关闭桌面合成器） |
| 拼音整句转换 | < 1 ms / 键 |

## 科学实验：个性化校准

- **基线**：板上 649 次真实按键，每键平均系统偏差 22 px，41% 落在键边缘附近，误触率 1.8%。
- **留出法回放**：前半学习每键偏移（取一半、限 ±15 px，与 Agnes 校准规则一致），后半回放检验：误触率 2.1% → 3.7%，系统偏差仅降 7%。
- **结论**：跨会话偏差不稳定，一次性静态校准无效，应按会话持续在线微调。数据与脚本见 `实验数据/`，可用 `desktop/experiment.py` 复现；同场景对照实验流程见脚本说明。

## 运行

```bash
cd work/keyscreen
./deploy.sh          # 部署到板子（首次）
./demo.sh start      # 启动电脑端（安装自启后无需手动）
```

浏览器打开 `http://127.0.0.1:43125/` 进入控制台，`/pitch.html` 为答辩演示。
