# KeyScreen：会思考的触屏键盘

2026 江苏省 AI+科学与工程创新实践黑客松 参赛作品

## 一句话介绍

一块触摸屏（LubanCat 1H）插到电脑上就是一把标准 USB 键盘；接入 Agnes（agnes-3.0-flash），通过设备协议 MHS 读取打字数据、调整键位、切换键盘语言、更换壁纸、指挥猫娘桌宠，让键盘随人、随场景、随语言变化。

## 功能

- **即插即用 USB 键盘**：模拟标准 HID 键盘，任何电脑免驱；多点触控、组合键、长按连发。电脑复位 USB 后自动重连。
- **多语言键盘**：英语 QWERTY、俄语 ЙЦУКЕН、法语 AZERTY、德语 QWERTZ。键帽即时换字，电脑端自动切到对应 Windows 布局（< 1 秒），切回时恢复用户原输入法。
- **一句话定制**：例如"我要开始写俄语论文了"，Agnes 自主规划 5 步工具调用：切俄语、选专注壁纸、配主题色、桌宠打气、用中俄双语鼓励。
- **屏上 Agnes 助手**：键盘上半屏即对话框，内置搜狗式整句拼音输入法（4.7 万词条、简拼、自学习）。
- **AI 动手改硬件**：MHS 工具 `get_touch_stats / adjust_key / set_language / set_wallpaper / pet_act …`，每次调用有日志。
- **有温度的交互**：会跑会跳、可拖拽的猫娘桌宠，苹果风格天气卡片，视频壁纸。
- **可靠性**：板端开机自启（冷启动 35 秒可用），电脑登录后自动连接；Agnes 不可用时本地规则兜底；Agnes 会话自动轮换，避免长会话卡死。

## 架构

```
触摸屏 → LubanCat 1H（渲染/判键/输入法/桌宠） → USB HID → 电脑（布局随键盘语言自动切换）
                     ↕ 网络（REST API）
          MHS 设备 keyscreen-01 ⇄ AgnesHub / AGH ⇄ agnes-3.0-flash
```

## 实测指标

| 指标 | 数值 |
|---|---|
| 触摸 → USB HID 发送 | 平均 1.75 ms，p95 3.3 ms |
| 按键 → 屏幕更新（助手输入） | 中位数约 34 ms |
| 屏幕刷新耗时 | 48 → 27 ms（关闭桌面合成器） |
| 拼音整句转换 | < 1 ms / 键 |
| 切换键盘语言 | 板端即时，电脑布局 < 1 秒 |
| 板子冷启动到可用 | 约 35 秒 |

## 科学实验：个性化校准

- **基线**：649 次真实按键，每键平均系统偏差 22 px，41% 落在键边缘附近，误触率 1.8%。
- **留出法回放**：前半学习偏移（取一半、限 ±15 px，与 Agnes 规则一致），后半检验：误触率 2.1% → 3.7%，偏差仅降 7%。
- **结论**：跨会话偏差不稳定，一次性静态校准无效，应按会话持续在线微调。脚本与数据见 `实验数据/`，可用 `desktop/experiment.py` 复现。

## 社会价值

- **外语学习者与跨境工作者**：一块屏幕即四种语言键盘，键帽所见即所得，不用贴键盘贴纸、不用记布局。
- **无障碍**：落点统计 + AI 调整键位，可为手部不便的用户放大、平移常用键。
- **低成本**：基于国产开发板与开源软件，整机成本远低于多块实体外语键盘。
