# 同场景对照实验（约 7 分钟，必须真人打字）

在 WSL 终端执行，`cd ~/keyscreen/work/keyscreen`：

1. `python3 desktop/experiment.py start before`，关闭助手对话框，在电脑记事本里用板子反复输入提示的句子约 3 分钟
2. `python3 desktop/experiment.py stop`
3. `python3 desktop/experiment.py calibrate`（Agnes 读取刚才的数据并调整键位，约 1 分钟）
4. `python3 desktop/experiment.py start after`，同样输入约 3 分钟
5. `python3 desktop/experiment.py stop`
6. `python3 desktop/experiment.py report`

结果写入 `evidence/experiment/compare.*`，并自动更新答辩页实验图。无论结果好坏都如实使用。
