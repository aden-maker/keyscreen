# 现场演示流程（约 5 分钟）

1. **插上即用（30 秒）**：USB 线插电脑，板子亮屏；打开记事本直接打字，说明"免驱、标准键盘"。
2. **场景化外观（40 秒）**：在键盘上打开 Agnes 助手，输入"换一个适合晚上的壁纸"，展示壁纸与配色变化、看板娘反应。
3. **中文输入（40 秒）**：在助手里用拼音输入"今天天气怎么样"，展示整句候选、简拼（nh → 你好）。
4. **AI 动手调硬件（60 秒）**：输入"分析我的打字习惯并校准按键"，展示 Agnes 调用 get_touch_stats / adjust_key 的步骤与键位变化。
5. **科学实验（60 秒）**：切到答辩页实验页，讲基线 22 px 系统偏差与"一次性校准无效 → 需在线持续校准"的发现。
6. **可靠性（30 秒）**：拔掉网线/断网，再问一次，展示"（离线模式）"本地兜底；天气卡片仍显示。
7. **收尾**：指标表 + 下一步（无障碍、按应用自动切换键盘）。

备用：若板子网络异常，先 `./demo.sh stop`，再重新插拔 USB，约 10 秒自动恢复。
