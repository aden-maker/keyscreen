# 作品简介（50 字以内）

触摸屏变身免驱USB四语言键盘，Agnes经MHS工具一句话改键位、壁纸、桌宠，AI亲手改造硬件。

# 作品详情（5000 字以内）

## 一、作品概述

KeyScreen 是一块"会被 AI 改造"的多语言触屏键盘。硬件只有一块国产 LubanCat 1H 开发板和一块电容触摸屏，外壳是自己裁的纸板；开发板通过 USB OTG 把自己模拟成标准 HID 键盘，插到任何电脑上都免驱可用。与普通键盘不同的是，这块键盘整体是"软"的：键区、键帽文字、语言布局、壁纸、配色、按键特效、桌宠，全部由软件渲染，也全部可以被程序修改。我们把这些修改能力封装成一组设备工具，以 MHS 设备的身份接入 Agnes Harness（AGH），让 agnes-3.0-flash 大模型能够读取键盘状态并直接操作硬件：用户只需说一句"我要写俄语论文了，帮我把键盘配好"，Agnes 就会自主规划、连续调用多个工具，把键盘切成俄语布局、换上适合专注的壁纸和配色、让桌宠加油打气，最后复核状态并用中俄双语回复。整个过程在真实设备上耗时约 17 秒、6 次工具调用，每一步都有可导出、可核验的执行记录。

作品的核心主张是：大模型不应只停留在屏幕里聊天，而应该能够安全、可审计地"动手"改变身边的硬件；而键盘这一最贴近人手的外设，恰好是检验这一主张的最佳载体。

## 二、要解决的问题

1. 外语键盘要买、要贴、切换易错。写俄语、法语、德语作业的同学要么额外购买外语键盘，要么在键帽上贴贴纸；系统切换布局后键帽和实际输出对不上，天天打错。
2. 触屏键盘千人一面。每个人手指的大小、习惯落点都不同，但触屏键盘给所有人同一套按键区域。我们在板上采集 649 次真实按键后发现，每个键平均存在约 22 像素的系统性落点偏差，41% 的按键落在键的边缘附近。
3. AI 不会动手。大模型很会聊天，却很少真正操作身边的硬件；即使能操作，也缺少参数校验、权限边界和执行日志，用户不敢放手。
4. 开发板上没有中文输入法。LubanCat 1H 运行 Debian 10 与 Python 3.7，没有可用的中文输入法，屏上的 Agnes 对话框无法用中文输入。
5. 外设定制门槛高。换壁纸、改键位、按应用切换配色，传统上都要进设置页面逐项操作，普通用户很少真正用起来。

## 三、实现方案与系统架构

系统由两条链路组成。

打字链路：触摸屏（Linux evdev 多点触控）→ LubanCat 1H（触点判键、键区渲染、整句拼音输入法、桌宠与壁纸动画）→ USB HID 标准键盘报文 → 电脑。板端用 Python 实现完整的渲染与输入循环，键盘以 1920×1080 坐标系描述每个键的矩形区域；多点触控支持组合键（Ctrl、Shift、Alt 与字母同时按下）和长按连发；USB 以 HID 规范的 8 字节键盘报文输出，不依赖任何驱动。实测触摸到 HID 报文发出平均 1.75 毫秒、p95 约 3 毫秒；按键到屏幕更新中位数约 34 毫秒；在定位到桌面合成器是刷新瓶颈并将其关闭后，屏幕刷新耗时从 48 毫秒降到 27 毫秒。

智能链路：板端 REST API（端口 8765）⇄ 局域网 ⇄ 电脑端客户端面板 ⇄ MHS 设备 keyscreen-01 ⇄ AGH ⇄ agnes-3.0-flash。板端对外暴露状态读取、截图、触点注入、语言切换、Profile 修改、壁纸管理、桌宠动作、对话收发等接口；电脑端把这些接口注册为 MHS 设备工具，由 AGH 负责会话管理、工具路由与执行记录。Agnes 可调用的工具共 9 个：read_device（读取设备状态）、get_touch_stats（读取逐键触点统计）、adjust_key（小步平移键位）、set_language（切换语言布局）、set_wallpaper（设置壁纸）、set_profile（修改主题色、文字阴影、键帽映射）、list_wallpapers（列出可用壁纸）、pet_say 与 pet_act（让桌宠说话、做动作）。所有写操作都要经过板端校验：偏移被钳制在 ±40 像素以内，未知语言、未知壁纸、未知按键一律返回 400 拒绝，每次调用都写入日志，并可用 agh export 导出为 HTML 或 JSONL（自动脱敏）供评委逐条核验。

电脑端客户端是一个本地网页，会自动发现并连接键盘，顶部实时显示触摸到 USB 的延迟，从上到下包含七个模块：Agnes 助手（四个预设指令和自然语言输入，显示每次工具调用的名称、结果与耗时）、键盘实时画面（与板子屏幕同步的壁纸、天气、桌宠、键帽）、壁纸（上传 PNG/JPG/WebP 静态图或 GIF/MP4 动态壁纸，板子自动解码循环播放）、按键特效（光晕、涟漪、粒子、图片四种动效，可跟随主题色、可调时长、可按单键设置）、外观与应用 Profile（壁纸、主题色、文字阴影、键帽文字打包成 Profile，按应用进程名自动切换）、按键统计（每键次数、误触率、落点偏移、按住时长）和触摸热力图（每次触摸的真实坐标按命中/误触着色绘制在键盘轮廓上）。

## 四、核心功能

1. 即插即用 USB 键盘。模拟标准 HID 键盘，支持多点触控、组合键、长按连发，Windows、macOS、Linux 免驱；电脑复位 USB 后板端自动重新枚举；板端开机自启，冷启动约 35 秒即可使用。
2. 四语言键盘与电脑布局自动跟随。英语 QWERTY、俄语 ЙЦУКЕН、法语 AZERTY、德语 QWERTZ 四套布局，点一下换语言键，键帽立刻换字。由于 USB 键盘发送的是键位而不是字符，我们让电脑端面板在板端切换语言的同时、1 秒内同步切换 Windows 键盘布局，切回时恢复用户原来的输入法；语言切换有 Agnes 工具、板端快捷键、面板按钮三条通道互为备份。
3. 一句话多步定制。用户只描述目标，不描述步骤。Agnes 自主规划并连续调用工具完成语言、壁纸、配色、桌宠的整套配置，并在最后读取状态复核。真实任务"我要写俄语论文了"由 agnes-3.0-flash 连续执行读状态 → 切俄语 → 浏览壁纸 → 设壁纸与配色 → 桌宠欢呼 → 再读状态复核共 6 步。
4. 屏上 Agnes 助手与自研整句拼音输入法。键盘上半屏就是 Agnes 对话框，可以直接用中文提问。为此我们在板上自研了搜狗式整句拼音输入法：4.7 万词条、Viterbi 整句转换、简拼、用户词自学习，每键计算耗时小于 1 毫秒，词库异步加载不阻塞开机。
5. AI 动手改键位。板端持续记录每个键的触点落点、按住时长与命中/误触，Agnes 通过 get_touch_stats 读取后，可以指出误触率最高和最容易按偏的键，并用 adjust_key 小步平移键位，让键盘慢慢贴合用户的手型。
6. 外观与 Profile 系统。壁纸、主题色、文字阴影、键帽文字映射打包成 Profile，可按应用进程名绑定：切到代码编辑器自动变成写代码配色并把键帽显示成快捷键的中文说明，切回聊天软件自动还原；壁纸支持视频动态壁纸。
7. 有温度的交互。可拖拽、会跑会跳的代码绘制猫娘桌宠，Agnes 可让它挥手、跳舞、欢呼，成为 AI 操作结果的可见反馈；苹果风格天气小组件由电脑端每分钟推送一次。
8. 可靠性设计。Agnes 不可用时电脑端自动切换为本地规则兜底回复；Agnes 会话自动轮换，避免长会话卡死；USB 断开自动重连；所有失败都有明确的错误码与提示。

## 五、技术亮点与创新点

1. AI 真正动手改硬件，且可审计、可还原。键盘不是被"聊"的对象，而是被"操作"的对象。MHS 设备把硬件能力暴露为工具，AGH 记录每一步的参数与返回值；板端对所有写操作做参数校验与范围钳制，保证模型即使给出离谱参数也不会把键盘弄坏。
2. 一句话多步自主规划。模型不是被动执行单条命令，而是根据目标自己决定调用顺序，并在最后复核结果，形成"感知—规划—执行—验证"的闭环。
3. 解决 HID 只发键位不发字符的根本矛盾。板端换字与电脑端换布局同步进行，并恢复原输入法，使"所见即所得"在四种语言之间真正成立。
4. 在资源受限的国产开发板上自研整句拼音输入法。Debian 10 + Python 3.7 环境下没有现成方案，我们用词图加 Viterbi 实现了 4.7 万词条的整句转换，并把单键耗时控制在 1 毫秒以内。
5. 数据驱动的个性化校准，并用科学实验检验。我们对 649 次真实按键做了基线统计，证实每键约 22 像素的系统性偏差；再用留出法回放（按时间对半分，前半学习每键偏移，后半检验）检验"一次性静态校准"的效果，结果显示跨会话偏差不稳定，静态校准并没有降低误触。我们如实报告这个负结果，并据此把设计改为由 Agnes 按会话持续、小步地在线调整。实验脚本与原始数据随附，可完整复现。
6. 整机成本约 300 元，不装驱动，所有源代码开源且不含任何密钥，是国产开发板上"AI + 硬件"的完整样例。

## 六、测试与验证

tools/run_tests.py 在真实设备上自动运行 11 条测试并全部通过：正常 4 条（AGH 多步任务、快捷换语言、只读分析、整句拼音），边界 4 条（未知语言、空消息、偏移超限钳制、英文原样输出），失败 3 条（未知壁纸、未知按键、模型不可用时离线兜底）。脚本同时自动生成测试样例表、AGH 执行记录导出（HTML/JSONL）、执行前后的设备状态与屏幕截图，全部收录在"运行证据"与"测试样例"目录中。

## 七、工程实践与攻克的难点

1. 刷新卡顿的定位。早期每次按键屏幕要 48 毫秒才能更新，我们逐层测量渲染、合成、显示的耗时，最终定位到 xfwm4 桌面合成器每次都重新合成整个 1080p 画面，在 bringup 脚本中关闭后降到 27 毫秒；渲染层采用脏矩形策略，每帧只重绘变化区域。
2. 多点触控与 HID 报文。evdev 的多触点事件要映射到 HID 的 6 键无冲 boot 报文，修饰键的按下与释放顺序处理不好就会"粘键"。我们按触点槽位记录每个手指按住的键：单独点按修饰键会锁存到下一个键（再点一次取消），按住修饰键再按其他键则作为普通组合键；连发由主机的 typematic 机制完成，板端只需如实上报按住状态。所有这些都用触点注入接口做了自动化回归测试。
3. 词库加载与开机时间。4.7 万词条的拼音词库一次性加载会拖慢开机，改为后台线程异步加载，不阻塞界面与打字。
4. 语言切换的三重保障。Agnes 工具、板端快捷键、面板按钮三条通道都能切语言，电脑端通过监听板端状态变化统一切换 Windows 布局，避免任何一条通道遗漏。
5. 模型行为的边界。模型偶尔会给出超范围的偏移或不存在的壁纸名，板端把钳制和拒绝做在 API 层而不是提示词里，保证无论模型怎么说，硬件都在安全范围内。
6. 现场可靠性。为答辩现场准备了开机自启、USB 热插拔重连、Agnes 会话自动轮换、模型不可用时离线兜底，以及故障速查卡、现场演示流程与完整的可复现运行说明。

## 八、部署与可复现性

板端只需把源代码目录放到 LubanCat 1H 上执行 bringup.sh，即完成依赖安装、USB Gadget 配置、服务自启与 REST API 启动；电脑端运行客户端面板并配置 AGH 与 MHS 设备即可。所有 API 密钥仅存放于本机受权限保护的目录，源代码与提交材料中不含任何密钥。tools/run_tests.py 与 demo.sh 可在真实设备上一键复现全部测试样例与演示流程，实验脚本与原始数据同样随附。

## 九、实际应用场景与价值

外语学习与考试：俄、法、德专业学生写作业、练打字，一块屏四种语言，教师机一键切换，无需贴键帽。跨境电商与外贸办公：客服在多语言之间秒切，一句话进入"俄语客服模式"。无障碍与适老：按个人落点习惯调整键区、放大键帽，AI 主动建议调整。创客教育：国产开发板上 AI 操作硬件的完整开源样例，REST API 与 MHS 工具可继续扩展新技能。展厅与公共终端：多语言访客共用一块屏，外观主题随活动一句话切换。开发者副屏：写代码配色加快捷键区，Agnes 对话框常驻而不占主屏。

## 十、展望

下一步我们计划：把校准从"按会话小步调整"扩展为按用户建模的自适应键区；增加日语、韩语等更多语言布局与对应的电脑端输入法联动；把 MHS 工具集开放给其他 Agnes 技能，让键盘成为桌面上可被多个智能体共享的通用输入与显示设备。

KeyScreen 用三百元的一块屏，既做成了四种语言的键盘，也做成了一个能被 AI 安全操作的硬件范例——让键盘随人而变。
