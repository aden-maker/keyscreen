# 第三方素材与数据来源声明

本作品如实列出所使用的第三方素材、数据、软件与服务。除下列内容外，作品的系统设计、板端程序、电脑端程序、测试与实验均由本队成员完成。

| 类别 | 名称 | 用途 | 来源 / 许可 |
|---|---|---|---|
| 大模型 | Agnes agnes-3.0-flash | 运行时任务规划、工具调用、复核与回复 | 赛事提供的 Agnes 平台 API |
| 智能体框架 | Agnes Harness（AGH）、MHS SDK | 会话、工具路由、设备协议、执行记录导出 | 赛事提供 |
| 壁纸图片 | 哲风壁纸（haowallpaper.com） | 键盘背景壁纸（个人非商用展示） | 网站公开下载，版权归原作者 |
| 天气数据 | wttr.in | 屏幕天气小组件 | 公开免费接口 |
| 输入法词典 | jieba 词频表 + pypinyin 注音 | 由 `tools/mkpinyin.py` 生成 `pinyin.txt` | MIT 许可 |
| 字体 | 文泉驿（WenQuanYi） | 板端中文显示 | GPL 字体例外许可 |
| 运行库 | pygame、aiohttp、evdev | 渲染、HTTP 服务、触摸输入 | LGPL / Apache-2.0 / BSD |
| 系统 | Debian 10（LubanCat 官方镜像）、Linux USB configfs gadget | 板端系统与 USB HID | 野火官方镜像 / GPL |
| 开发辅助 | Cursor AI 编程助手 | 辅助编写与调试部分代码、文档初稿 | 队员审阅、上板验证并对结果负责 |

数据说明：
- 按键与触点数据全部来自本队在自有设备上的真实打字，不含他人个人信息；实验原始数据与脚本随附，可复现。
- 桌宠（猫娘）形象由程序代码绘制，未使用第三方图片。
- 演示与截图均为真实设备运行画面，未经合成。
