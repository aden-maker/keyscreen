【作品概述】
KeyScreen 把一块 LubanCat 1H 触摸屏变成即插即用的 USB 键盘：插到任何电脑上免驱即可打字。我们接入 Agnes 大模型（agnes-3.0-flash），通过设备协议 MHS 让 AI 直接读写键盘硬件——读取打字数据、调整键位、切换键盘语言、更换壁纸与配色、指挥猫娘桌宠，让键盘随人、随场景、随语言变化。

【要解决的问题】
1. 键位千人一面：每个人手指落点不同，触屏键盘却给所有人同一套按键区域。
2. 外观和语言固定：写代码、写外语论文、演示需要的键盘不同，实体键盘无法随需求变化，外语键盘还要额外购买或贴贴纸。
3. AI 只停留在屏幕里：大模型会聊天，却很少真正动手改变身边的硬件。

【系统架构】
触摸屏(evdev 多点触控) → LubanCat 1H(渲染、判键、输入法、桌宠) → USB HID 标准键盘 → 电脑
板端 REST API ⇄ 网络 ⇄ MHS 设备 keyscreen-01 ⇄ AgnesHub/AGH ⇄ agnes-3.0-flash
Agnes 可调用 get_touch_stats、adjust_key、set_language、set_wallpaper、pet_act 等工具，每次调用都有日志可查。

【核心功能】
1. 即插即用 USB 键盘：模拟标准 HID 设备，支持多点触控、组合键、长按连发，任何系统免驱；电脑复位 USB 后自动重连。
2. 多语言键盘：英语 QWERTY、俄语 ЙЦУКЕН、法语 AZERTY、德语 QWERTZ，键帽即时换字；电脑端自动切换到对应的 Windows 键盘布局（1 秒内），切回时恢复用户原来的输入法。
3. 一句话定制：说"我要开始写俄语论文了"，Agnes 自主规划并连续调用 5 次工具：切俄语键盘、挑选适合专注写作的壁纸、配沉稳主题色、让桌宠加油，最后用中俄双语鼓励。
4. 屏上 Agnes 助手：键盘上半屏就是对话框，内置搜狗式整句拼音输入法（4.7 万词条 Viterbi 整句转换、简拼、用户词自学习）。
5. AI 动手改硬件：Agnes 读取每个键的触点统计，自动平移偏差较大的键位。
6. 有温度的交互：可拖拽、会跑会跳的猫娘桌宠，苹果风格天气小组件，视频动态壁纸。
7. 可靠性：板端开机自启（冷启动约 35 秒），电脑登录后自动连接；Agnes 不可用时本地规则兜底；Agnes 会话自动轮换，避免长会话卡死。

【实测指标（板上测量）】
- 触摸到 USB HID 发送：平均 1.75 ms，p95 3.3 ms
- 按键到屏幕更新：中位数约 34 ms
- 屏幕刷新耗时：48 ms → 27 ms（定位到桌面合成器瓶颈并关闭）
- 拼音整句转换：每键小于 1 ms
- 切换键盘语言：板端即时，电脑布局小于 1 秒

【科学实验：AI 个性化校准】
基线：板上 649 次真实按键，每个键平均存在 22 px 的系统性落点偏差，41% 的按键落在键边缘附近。
留出法回放：按时间对半分，前半学习每键偏移，后半检验。结果显示跨会话偏差不稳定，一次性静态校准没有降低误触。
结论：校准应由 Agnes 按会话持续、小步地在线调整。实验脚本与原始数据均已附上，可完整复现。

【AGH 的作用与多步执行】
AGH 是系统的智能体底座：电脑端面板把用户的话交给 agh（打印模式，json 输出），AGH 负责会话管理、工具路由与执行记录；MHS 设备 keyscreen-01 把键盘的每个能力暴露为工具（read_device、get_touch_stats、adjust_key、set_language、set_wallpaper、set_profile、list_wallpapers、pet_say、pet_act）。一次真实的"俄语写作"任务中，agnes-3.0-flash 连续执行 6 步：读状态 → 切俄语 → 浏览壁纸 → 设壁纸与配色 → 桌宠欢呼 → 再读状态复核，耗时 28–39 秒，执行记录可用 agh export 导出为 html/jsonl（自动脱敏），随附在"运行证据"中。

【五大创新点】
1. AI 真正动手改硬件：键盘不是被"聊"的对象，而是被"操作"的对象。所有写操作经板端 API 校验与钳制（偏移 ±40 px，未知值 400 拒绝），可审计、可还原。
2. 一句话多步定制：用户只说目标，Agnes 自主规划并连续调用工具完成语言、壁纸、配色、桌宠的整套配置，并在最后复核。
3. 四语言键盘与电脑布局自动跟随：解决了 HID 只发键位不发字符的根本矛盾——板端键帽换字的同时，电脑端 1 秒内切换 Windows 布局，切回时恢复用户原输入法；三条切换通道互为备份。
4. 板上自研整句拼音输入法：Debian 10 + Python 3.7 的开发板上没有现成中文输入法，自研 Viterbi 整句转换（4.7 万词条、每键 < 1 ms、简拼、用户词自学习）。
5. 数据驱动的个性化校准，并用科学实验检验：逐键落点统计 → Agnes 读取 → 小步校准；留出法实验如实报告"静态一次性校准无效"，据此把设计改为按会话持续在线调整。

【解决了哪些问题】
- 外语键盘要买、要贴、切换易错 → 一块屏四种语言，所见即所得，电脑布局自动跟随（证据：截图、测试样例、视频）。
- 触屏键盘千人一面、误触 → 逐键落点统计 + AI 在线小步校准（证据：实验数据 baseline/replay）。
- AI 不会动手 → MHS 工具 + AGH 多步执行闭环（证据：AGH 执行记录 html/jsonl）。
- 板上没有中文输入法 → 自研整句拼音输入法（证据：测试样例）。
- 外设定制门槛高 → 一句话定制（证据：俄语写作模式截图）。
- 演示与长期运行不稳定 → 自启、HID 重连、会话轮换、离线兜底（证据：冷启动与失败类测试）。

【实际应用场景】
- 外语学习与考试：俄/法/德专业学生写作业、练打字；教师机一键切换，无需贴键帽。
- 跨境电商与外贸办公：客服在多语言之间秒切；一句话切换"俄语客服模式"。
- 无障碍与适老：按个人落点习惯调整键区、放大键帽；AI 主动建议调整。
- 创客教育：国产开发板上"AI + 硬件"的完整开源样例，REST API + MHS 工具可扩展新技能。
- 展厅与公共终端：多语言访客共用一块屏，外观主题随活动一句话切换。
- 开发者副屏：写代码配色 + 快捷键区，Agnes 对话框常驻不占主屏。

【测试与验证】
tools/run_tests.py 在真实设备上自动运行 11 条测试（正常 4、边界 4、失败 3），全部通过，并自动生成测试样例表、AGH 执行记录导出、前后状态与截图。失败类包括模型不可用场景：AGH 以非零退出码报告原因，电脑端切换为本地规则兜底回复。

【社会价值】
外语学习者与跨境工作者一块屏幕即可获得四种语言键盘，所见即所得；落点统计与 AI 调键位可服务手部不便的用户；基于国产开发板，成本低。
