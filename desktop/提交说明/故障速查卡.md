# 现场故障速查卡

| 现象 | 处理 |
|---|---|
| 屏幕能点，电脑收不到字 | 拔插板子 OTG 口的 USB 线（必须是数据线，直插电脑，不经扩展坞），等 5 秒 |
| 板子黑屏 / 无反应 | 断电重启，约 35 秒后自动可用 |
| 助手一直"思考中" / 提示电脑端没连上 | WSL 终端执行：`cd ~/keyscreen/work/keyscreen && ./demo.sh stop && nohup setsid bash ./demo.sh watch &` |
| Agnes 回复"（离线模式）" | 网络或额度问题；快捷按钮仍可用，继续演示，事后检查网络 |
| 换语言后电脑打出的字不对 | 再点一次"换语言键盘"或输入"英语键盘"；布局只作用于当前前台窗口 |
| 天气卡片不见了 | 电脑端每分钟会自动推送一次，等 1 分钟 |
| 触摸没反应 | 拔插触摸屏的 USB 线，程序会自动恢复 |

演示前检查：数据线 + 备用线、电脑已登录、记事本打开、键盘语言为英语、网络正常。
