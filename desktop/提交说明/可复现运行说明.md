# 可复现运行说明

## 硬件
- LubanCat 1H（Debian 10 官方镜像）+ 触摸屏；USB-C OTG 口接电脑（作键盘），网口与电脑直连或同一局域网。
- Windows 10/11 电脑，装 WSL Ubuntu（运行 AGH、MHS 设备进程与面板）。

## 1. 板端部署（一次性）
```bash
scp -r board cat@<板子IP>:/home/cat/keyscreen/
ssh cat@<板子IP>
sudo sh /home/cat/keyscreen/board/bringup.sh   # 一键安装依赖(离线 wheels)、配置 USB HID、注册并启用 systemd 服务，可重复运行
sudo systemctl start keyscreen
```
`hid_gadget.sh` 会在服务启动时配置 USB HID（强制 OTG 为 peripheral 模式）。开机约 35 秒后电脑识别出 USB 键盘即可直接打字。
检查：`curl http://<板子IP>:8765/api/profile` 返回 JSON。

## 2. 电脑端（WSL）
```bash
pip3 install aiohttp
# AGH：按赛事文档安装 Agnes Harness，执行 agh doctor 确认模型 agnes-3.0-flash 可用
# 密钥放在 .agh/secrets/（chmod 600），不要写入代码
BOARD=http://<板子IP>:8765 bash demo.sh   # 启动 MHS 设备 keyscreen-01 + 面板（Agnes 对话桥接、键盘布局跟随）
```

## 3. 验证
- 键盘：屏幕上打字，电脑记事本出字。
- 语言：屏幕上点"换语言键盘"，键帽变俄语，电脑布局 1 秒内同步。
- Agnes 多步：屏幕点"俄语写作"或在电脑运行
  `agh -p "我要开始写俄语论文了，帮我把键盘配置好" --mode json`
- 一键测试与证据：`python3 tools/run_tests.py`，结果写入 `evidence/submission/`（测试样例.md、AGH 执行记录 html/jsonl、前后状态、截图）。
- 对照实验：`python3 desktop/experiment.py baseline|replay`，输出 svg/json/md。

## 常见问题
见《故障速查卡.md》：电脑不识别键盘先重插线；Agnes 无响应时面板自动轮换会话并启用离线兜底。
